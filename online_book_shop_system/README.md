# Online Book Shop System

## 📌 Project Overview
This is a Spring Boot–based Online Book Shop System developed as a class assignment.

## 👥 User Roles
- Guest
- Customer
- Staff
- Manager
- Admin (manage user accounts only)

## 🛠️ Technologies
- Java 17
- Spring Boot
- Spring Data JPA
- SQL Server / MySQL
- Postman

## 📚 Features
- Book CRUD (Create, Read, Update, Delete)
- Order Management
- User Management (Admin)
- RESTful APIs

## ▶️ How to Run
1. Configure `application.properties`
2. Run `OnlineBookshopApplication`
3. Test APIs using Postman
